# tray-translate

> 完全オフラインで高速に動作する常駐型・機械翻訳ツール（CTranslate2 + SentencePiece + egui/eframe）

`tray-translate` は、Argos Translate の翻訳モデルをベースに、外部サーバーとの通信を一切行わずローカル PC 上で完結する軽量常駐翻訳ツールです。

---

## 主な特徴

- **完全オフライン動作**: 翻訳実行時に外部 API やインターネットへの通信は一切行いません（[ADR-002](docs/adr/002-target-platform-and-environment-policy.md) 準拠）。
- **タスクトレイ常駐 & グローバルホットキー**: `Ctrl+Alt+T`（カスタマイズ可能）でいつでも瞬時に最前面に呼び出し。閉じるボタン（×）でトレイへ最小化格納。
- **クリップボード自動翻訳**: ブラウザやエディタ等でコピーした英文を自動検知して即座に翻訳。翻訳結果の自動コピーにも対応。
- **軽量省メモリ & アイドル時自動解放**: ネイティブ GUI（egui/eframe）による高速起動。未使用時はモデルインスタンスを自動解放して待機メモリを最小化。
- **安全なモデル管理**: 公式モデル（英日、日英など）をワンクリックで安全にダウンロード（HTTPS強制、Zip Slip対策、原子的導入）。
- **文分割と構造維持**: 日本語などの分かち書きを行わない言語への自然な訳文結合、および改行・段落レイアウトの自動保持。
- **CLI / GUI の両対応**: コマンドラインからのパイプ翻訳・スクリプト連携用の `tt` コマンドも同梱。

## 使い方 (GUI)

1. `tt-gui.exe` を起動します。
2. タスクトレイに青い「T」アイコンが表示され、翻訳ウィンドウが開きます。
3. **モデルの導入**:
   - 上部の「モデル管理」タブを開き、「公式モデル一覧を取得 (通信)」をクリックします。
   - `en_ja`（英語→日本語）や `ja_en`（日本語→英語）の「取得」ボタンをクリックしてダウンロードします。
4. **翻訳の実行**:
   - 「翻訳」タブに戻り、テキストを入力して「翻訳」ボタンをクリックします。
   - グローバルホットキー（既定: `Ctrl+Alt+T`）を押すことで、他の作業中でも即座にウィンドウが表示されます。
5. **設定の変更**:
   - 「設定」タブで、ホットキー、アイドル時のモデル解放秒数、クリップボード監視・自動コピーの ON/OFF などを調整できます。

## 使い方 (CLI)

```bash
# パッケージ一覧の確認
tt list

# モデルのダウンロード (例: 英語 -> 日本語)
tt download en ja

# テキストの翻訳
tt translate en_ja "Rust is amazing. Offline translation works perfectly."

# パイプ入力（標準入力）からの翻訳
echo "Hello world" | tt translate en_ja -
```

---

## 環境変数

- **`TT_MODEL_DIR`**: 翻訳モデルの保存先ディレクトリ（未指定時は OS 標準のデータディレクトリ）
- **`TT_CONFIG_DIR`**: 設定ファイル（`settings.json`）の保存先ディレクトリ
- **`HTTPS_PROXY` / `HTTP_PROXY`**: モデルダウンロード時のプロキシ設定（OS のルート証明書ストアも利用）
