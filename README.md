# tray-translate

> 完全オフラインで高速に動作する常駐型・機械翻訳ツール（CTranslate2 + SentencePiece + egui/eframe）

`tray-translate` は、Argos Translate の翻訳モデルをベースに、外部サーバーとの通信を一切行わずローカル PC 上で完結する軽量常駐翻訳ツールです。

---

## 主な特徴

- **完全オフライン動作**: 翻訳実行時に外部 API やインターネットへの通信は一切行いません。通信が発生するのは、ユーザーがモデルの一覧取得・ダウンロードを明示的に指示したときだけです（[ADR-002](docs/adr/002-target-platform-and-environment-policy.md) 準拠）。
- **タスクトレイ常駐 & グローバルホットキー**: `Ctrl+Alt+T`（カスタマイズ可能）でいつでも瞬時に最前面に呼び出し。閉じるボタン（×）でトレイへ最小化格納（設定で終了への変更も可能）。
- **クリップボード自動翻訳**: ブラウザやエディタ等でコピーした英文を自動検知して即座に翻訳。翻訳結果の自動コピーにも対応。
- **翻訳履歴の保持・復元**: 翻訳したテキストを自動で記録し、アプリ再起動後も保持。過去の翻訳のワンクリック復元や個別削除・全消去に対応（重複自動マージ、最大件数制限、自動翻訳確定待ち、破損耐性）。
- **軽量省メモリ & アイドル時自動解放**: ネイティブ GUI（egui/eframe）による高速起動。未使用時はモデルインスタンスを自動解放して待機メモリを最小化。
- **安全なモデル管理**: 公式モデル（英日、日英など）をワンクリックで安全にダウンロード（HTTPS強制、Zip Slip対策、原子的導入）。ダウンロード内容のハッシュ検証は行いません。
- **文分割と構造維持**: 日本語などの分かち書きを行わない言語への自然な訳文結合、および改行・段落レイアウトの自動保持。
- **CLI / GUI の両対応**: コマンドラインからのパイプ翻訳・スクリプト連携用の `tt` コマンドも同梱。

## 使い方 (GUI)

1. `tt-gui.exe` を起動します。
2. タスクトレイに青い「T」アイコンが表示され、翻訳ウィンドウが開きます。
3. **モデルの導入**:
   - 上部の「モデル管理」タブを開き、「公式モデル一覧を取得 (通信)」をクリックします。
   - `en_ja`（英語→日本語）や `ja_en`（日本語→英語）の「取得」ボタンをクリックしてダウンロードします。
4. **翻訳の実行**:
   - 「翻訳」タブに戻り、テキストを入力して「翻訳」ボタンをクリックします（入力後の自動翻訳も利用可能）。
   - ウィンドウ下部の「履歴」セクションから、過去の翻訳履歴の確認や復元が可能です。
   - グローバルホットキー（既定: `Ctrl+Alt+T`）を押すことで、他の作業中でも即座にウィンドウが表示されます。
5. **設定の変更**:
   - 「設定」タブで、ホットキー、アイドル時のモデル解放秒数、クリップボード監視、翻訳結果の自動コピー、入力後の自動翻訳（待機時間）、タスクトレイ常駐、履歴の上限件数（0 で記録無効化）、履歴の確定待ち時間などを調整できます。

> [!NOTE]
> クリップボード監視を有効にしている場合、外部アプリケーション等でコピーしたテキストも自動翻訳され、翻訳履歴に記録されます。

## 使い方 (CLI)

```bash
# パッケージ一覧の確認
tt list

# モデルのダウンロード (例: 英語 -> 日本語)
tt download en ja

# テキストの翻訳
tt translate en_ja "Rust is amazing. Offline translation works perfectly."

# パイプ入力（標準入力）からの翻訳
echo "Hello world" | tt translate en_ja -
```

## ディレクトリ・構成概要

本プロジェクトは Cargo ワークスペースによるマルチクレート構成を採用しています。詳細なアーキテクチャ・責務境界・ライフサイクルの正本は [TT-BD-001 基本設計書](docs/design/TT-BD-001_基本設計書.md) を参照してください。

- **`crates/core/`** (`tray-translate-core`): 翻訳エンジン（CTranslate2 / SentencePiece）、パッケージ管理、文分割・行構造再構築ロジック（UI 非依存の純粋コア）
- **`crates/app/`** (`tray-translate-app`): アプリケーション制御層（設定管理、クリップボード監視、翻訳履歴の永続化、モデルダウンロード進行管理、非同期ワーカー）
- **`crates/cli/`** (`tt`): コマンドライン実行バイナリ
- **`crates/gui/`** (`tt-gui`): タスクトレイ常駐型デスクトップ GUI（egui / eframe）
- **`docs/`**: [ドキュメントガバナンス](docs/README.md) に基づく設計書・ADR・運用手順書・テスト証跡

---

## 環境変数

- **`TT_MODEL_DIR`**: 翻訳モデルパッケージの保存先ディレクトリ（未指定時は OS 標準のデータディレクトリ）
- **`TT_CONFIG_DIR`**: 設定ファイル（`settings.json`）および翻訳履歴（`history.json`）の保存先ディレクトリ（未指定時は OS 標準の設定ディレクトリ）
- **`HTTPS_PROXY` / `HTTP_PROXY`**: モデルダウンロード時のプロキシ設定（OS のルート証明書ストアも利用）
