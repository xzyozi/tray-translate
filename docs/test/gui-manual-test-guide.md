# GUI 手動テスト・動作確認手順書

本ドキュメントは、Issue #30 に基づき、Windows 実機環境において `crates/gui` (`tray-translate-gui`) の全機能を網羅的に手動確認・受入検証するための手順書である。

---

## 1. 事前準備 (Prerequisites & Setup)

### 1.1 必要な環境・ツール

| 項目 | 要件 | 備考 |
| :--- | :--- | :--- |
| OS | Windows 10 / 11 (64-bit) 実機 | GUI 描画および通知領域（タスクトレイ）の表示環境 |
| Rust ツールチェーン | Rust 1.99.1 以上, Cargo | `rustc --version`, `cargo --version` で確認 |
| 端末 / シェル | PowerShell (pwsh) または cmd | リポジトリルートで実行 |

### 1.2 初回翻訳モデルの導入

GUI 起動前に、CLI から英語→日本語 (`en` → `ja`) の翻訳モデルパッケージをダウンロード・配置する。

```powershell
# リポジトリルートで実行
cargo run --release --bin tt -- download en ja
```

- **正常終了の確認**:
  - `Successfully installed package to: ...` と表示されること。
  - Windows 標準の保存先 `%APPDATA%\tray-translate\packages`（または環境変数 `TT_MODEL_DIR` で指定したディレクトリ）内に `en_ja` パッケージが展開されていること。

### 1.3 GUI アプリケーションの起動

```powershell
# デバッグビルドでの起動
cargo run -p tray-translate-gui

# またはリリースビルドでの起動（推奨: 動作が高速）
cargo run --release -p tray-translate-gui
```

## 2. 基本機能の確認手順 (Basic UI & Translation)

### 2.1 ウィンドウ表示・レイアウト・フォント確認

1. **ウィンドウ表示とレスポンシブ左右分割・自動幅調整 (Issue #57)**:
   - 起動直後に「tray-translate」というタイトルのウィンドウ（初期サイズ: 640×560）が表示されること。
   - **幅 640px 以上**: 原文エリア（左）と訳文エリア（右）が左右均等に並ぶ「左右分割レイアウト（Side-by-Side）」で表示されること。
   - **自動幅調整（Auto-width）**: ウィンドウをマウスで横に伸縮させた際、左カラム・右カラムおよび中央の境界線がウィンドウ幅全体に追従して隙間なく均等に自動リサイズされること。
   - **幅 640px 未満**: ウィンドウ枠を狭める（最小 420px 付近）と、原文（上）・訳文（下）の「上下配置レイアウト」に自動で切り替わること。
2. **日本語フォント表示**:
   - タイトル、ラベル、ボタンテキストなどの日本語が文字化けや四角（豆腐: □）にならず、Windows システムフォント（游ゴシック / メイリオ等）で正常に描画されていること。
3. **初期ステータスとモデル認識**:
   - 最下部のステータスバー左側に控えめな弱調色（グレー）で「● 準備ができました」と表示されていること。
   - ステータスバー右側に「導入済み: en_ja」が小さめのフォント（11px）で安全に表示されていること。

### 2.2 手動テキスト入力と翻訳実行（非同期ワーカー検証）

1. **テキスト入力**:
   - 左側の「翻訳するテキスト」の入力欄に以下の英文を入力する。
     ```text
     Hello, world! This is a test for tray-translate.
     ```
2. **翻訳ボタン押下**:
   - 原文入力欄の下部にある「翻訳」ボタンをクリックする。
3. **非同期応答性の確認（重要）**:
   - クリック直後、「翻訳」ボタンが無効化（disabled）され、ボタンの表記が「翻訳中…」に変化すること。
   - ステータスバーに「翻訳中…（初回はモデルの読み込みに時間がかかります）」と表示されること。
   - **翻訳処理実行中も、ウィンドウ自体のドラッグ移動やサイズ変更が滑らかに行え、UI が一切フリーズ（「応答なし」）しないこと**（PR #40 で導入されたワーカースレッドの検証）。
4. **翻訳完了の確認**:
   - 処理完了後、ボタンが再び有効化され「翻訳」表記に戻ること。
   - 右側の「翻訳結果」欄に日本語訳（例: `こんにちは、世界！これはトレイ翻訳のテストです。`）が表示されること。
   - ステータスバーが「翻訳しました」に更新されること。

### 2.3 インライン操作ボタン（クリア・コピー）の確認 (Issue #59)

1. **インラインクリアボタン（×）の確認**:
   - 原文入力欄（左側）にテキストを入力すると、テキストエリア内部の右下にベクター描画された「クリア（×）」アイコンボタンが表示されること（テキストが空のときは非表示）。
   - マウスカーソルを合わせると、「入力をクリア」というツールチップが表示されること。
   - キーボードの `Tab` キーを押して移動した際に、クリアボタンにフォーカス枠が表示され、`Space` または `Enter` キーで押下できること。
   - クリアボタンを押すと、原文入力欄のテキストが即座に消去され、ボタンが非表示に戻ること。
2. **インラインコピーボタン（結果をコピー）の確認**:
   - 訳文表示欄（右側）の内部右下に、ベクター描画された「コピー」アイコンボタンが配置されていること（訳文が空のときは無効化/disabled）。
   - マウスカーソルを合わせると、「結果をクリップボードにコピー」というツールチップが表示されること。
   - キーボードの `Tab` キーでフォーカスが当たり、キー操作で押下できること。
   - コピーボタンをクリックすると、ステータスバーに「結果をクリップボードにコピーしました」と表示されるとともに、**約2秒間アイコンが緑色のチェックマーク（✓）に変化し、ツールチップが「クリップボードにコピーしました！」に切り替わること**。
   - メモ帳（Notepad）等を開いて `Ctrl + V` を押し、翻訳結果テキストが正確に貼り付けられることを確認する。
   - **自動コピー連携**: 設定で「翻訳結果の自動コピー」が有効な場合、翻訳完了時に自動でアイコンがチェックマーク（✓）に切り替わり、視覚的にコピー完了が通知されること。
3. **長文スクロール時の視認性**:
   - 原文または訳文に複数行の長文を入力・翻訳し、スクロールバーが表示される状態にしても、不透明背景と枠線によりインラインボタンが文字に埋もれず、クリック操作できること。
4. **翻訳ボタンの配置**:
   - 原文入力欄の直下に「翻訳」ボタン（翻訳中は「翻訳中…」・無効化）が配置されており、押しやすい位置にあること。

### 2.4 言語選択ドロップダウン・入れ替えボタンの確認 (Issue #57)

1. **言語選択ドロップダウンの自動幅調整と配置**:
   - 左右分割レイアウト時、左側の原文エリアの直上に「翻訳元」ドロップダウン、中央の境界線上に「⇆」入れ替えボタン、右側の訳文エリアの直上に「翻訳先」ドロップダウンが配置され、カラムの幅に合わせて自動幅調整（追従拡大）されること。
   - 「翻訳元」「翻訳先」がドロップダウン（ComboBox）形式になっており、導入済みモデルに基づいた言語一覧（例: `英語 (en)`, `日本語 (ja)` 等）が表示・選択できること。言語を切り替えても ComboBox の幅がガタつかないこと。
   - 言語を変更すると、即時に設定に反映・保存され、設定タブの「翻訳元言語コード」「翻訳先言語コード」とも同期すること。
2. **言語入れ替えボタン（⇆）の挙動仕様**:
   - **言語のみの入れ替え**: 翻訳元と翻訳先の選択言語のみが入れ替わる。入力済みのテキストや翻訳結果は保持され、勝手に消去・反転されたりしない。
   - **自動翻訳無効時の抑制**: 自動翻訳がオフの場合、言語を入れ替えただけで意図せず勝手に翻訳処理が走ることはない（自動翻訳有効時は入力テキストがあればデバウンス待機後に自動翻訳が走る）。
   - **逆方向未導入時の無効化**:
     - 逆方向（例: `ja` → `en`）のモデルパッケージが未導入の場合、入れ替えボタンが無効化（disabled）されること。
     - 無効化されたボタンにマウスカーソルを合わせると、「逆方向（ja → en）のモデルが未導入です」等の案内ツールチップが表示されること。
     - 両方向（`en_ja` と `ja_en`）が揃っている場合はボタンが有効化され、クリックで言語が入れ替わること。
3. **未導入モデルの警告表示**:
   - 未導入の言語ペアが指定されている場合、橙色で「未導入: {パッケージ名}」と警告が表示され、隣の「モデル管理で取得」ボタンを押すとモデル管理タブに切り替わること。

### 2.5 ステータスバーとインジケーター（スピナー・状態表示）の確認 (Issue #61)

1. **処理中インジケーター（スピナー）の確認**:
   - 「翻訳」ボタンをクリックした際、ステータスバーに青色のスピナー（`egui::Spinner`）が回転表示され、アクセント色で「翻訳中…」が表示されること。
   - 翻訳処理が完了すると、スピナーが即座に消去され、通常状態（Info: 「● 翻訳しました」）に復帰すること。
2. **状態表示（Info / Busy / Error）の識別確認**:
   - **通常情報 (Info)**: 「● 準備ができました」「● 設定を保存しました」等が控えめな文字色（`TEXT_WEAK`）で表示されること。
   - **処理中 (Busy)**: スピナー（12px）とアクセント色（`ACCENT`）で明示されること。
   - **エラー (Error)**: 警告アイコン「⚠」とともに赤色（`ERROR`）で表示され、通常メッセージと一目で区別できること。
3. **アイドル時の CPU 使用率の確認**:
   - 翻訳完了後、Windows タスクマネージャー等で `tt-gui.exe` の CPU 使用率が 0% に落ち着いていること（スピナー終了後に不要な再描画要求が停止していることの検証）。
4. **導入済みモデル一覧の表示安全性**:
   - ステータスバー右端に「導入済み: en_ja」と控えめな文字サイズ（11px）で表示され、モデル数が多い場合も `truncate` による省略（...）が行われ、ウィンドウ枠の横スクロールやレイアウト崩れが発生しないこと。

### 2.6 入力後の自動翻訳（デバウンス・古い結果破棄・自動コピー抑制）の確認 (Issue #60)

1. **設定項目の確認**:
   - 設定タブを開き、「入力後の自動翻訳」チェックボックス（既定: OFF）が存在することを確認する。
   - チェックボックスを ON にすると、「自動翻訳の待機時間」スライダー（100〜3000ms、既定: 800ms）が操作可能になること（OFF のときは無効化/disabled）。
   - スライダーの値を変更（例: 800ms → 500ms）し、「設定を保存」ボタンを押すと設定ファイルに保存されること。
2. **デバウンスタイマーによる自動翻訳**:
   - 翻訳タブに戻り、「入力後の自動翻訳」を有効にした状態で原文入力欄に英文を入力する（例: `This is an automatic translation test.`）。
   - タイピングを停止して 800ms（設定値）経過すると、**「翻訳」ボタンを押さなくても自動的に翻訳処理が開始**され、ステータスバーにスピナーと「翻訳中…」が表示されること。
   - 処理完了後、右側の「翻訳結果」欄に訳文が表示されること。
3. **タイピング中の古い翻訳結果破棄（RequestTracker の検証）**:
   - 原文入力欄で文字を素早く連続して追加・編集する（タイピングを継続する）。
   - 途中の未完成な入力に対する古い翻訳結果が画面に遅れて反映されることなく、**最後に入力を停止した最新のテキストに対する翻訳結果のみが反映されること**。
4. **クリップボード自動コピー抑制（安全制御 / ADR-006）**:
   - 設定で「翻訳結果の自動コピー」を ON にしておく。
   - 手動翻訳（「翻訳」ボタン押下）またはクリップボード監視翻訳の場合は、翻訳完了時にクリップボードへ自動コピーされる。
   - 一方、**入力後の自動翻訳（タイピングによるトリガー）時は、ユーザーの作業中クリップボードを意図せず破壊しないよう、自動コピーが無効化されること**（手動の「結果をコピー」インラインボタンからは通常通りコピー可能）。
5. **言語変更・クリア時のデバウンス制御**:
   - テキスト入力後にインラインクリアボタン（×）を押した際、自動翻訳タイマーがキャンセルされ、空の翻訳要求が送信されないこと。
   - 原文を入力した状態で言語ドロップダウンや言語入れ替えボタン（⇆）を操作した場合、新しい言語ペアに対して自動翻訳タイマーが再始動し、正しい言語ペアで翻訳されること。

## 3. クリップボード連携の確認手順 (Clipboard Integration)

### 3.1 クリップボード監視による自動翻訳（入力）

1. **監視機能の有効化**:
   - 「クリップボードを監視して自動翻訳する」チェックボックスを ON（チェックを入れる）にする。
   - ステータスバーに「設定を保存しました」と表示されること。
2. **外部アプリからのコピー検出**:
   - ブラウザやメモ帳などの外部アプリケーションで、以下の英文を選択してコピー (`Ctrl + C`) する。
     ```text
     Rust is a systems programming language focused on safety and speed.
     ```
3. **自動翻訳の実行確認**:
   - コピー後、約 1 秒以内（`TICK_INTERVAL`）に tray-translate の「翻訳するテキスト」欄へ自動入力され、翻訳処理が開始されること。
   - 完了後、「翻訳結果」欄に日本語訳が表示され、ステータスバーに「クリップボードの内容を翻訳しました」と表示されること。

### 3.2 翻訳結果の自動コピー（出力）と無限ループ防止（安全制御）

1. **自動コピーの有効化**:
   - 「翻訳結果を自動でクリップボードにコピーする」チェックボックスを ON にする（既定で ON）。
2. **自動コピー動作の確認**:
   - 外部アプリで英文をコピーするか、手動で「翻訳」ボタンを押す。
   - 翻訳完了後、ステータスバーが「〜（結果をクリップボードにコピーしました）」となること。
   - メモ帳等で `Ctrl + V` を実行し、翻訳後の日本語結果がクリップボードに入っていることを確認する。
3. **無限ループ防止の確認（重要）**:
   - 翻訳結果がクリップボードに書き込まれても、**クリップボード監視が自身の出力を拾って再翻訳するフィードバックループ（無限翻訳ループ）が発生しないこと**を確認する（`mark_written` / `NoteClipboardWritten` による既読制御の検証）。
   - ウィンドウが安定した待機状態を維持すること。

### 3.3 監視の無効化確認

1. **監視機能の停止**:
   - 「クリップボードを監視して自動翻訳する」チェックボックスを OFF にする。
2. **コピー非連動の確認**:
   - 外部アプリで別の英文をコピーしても、入力欄が更新されず自動翻訳が走らないことを確認する。

## 4. トレイ常駐機能の確認手順 (System Tray & Window Lifecycle)

### 4.1 タスクトレイ（通知領域）アイコンの確認

1. **アイコン描画**:
   - Windows タスクバー右下の通知領域（システムトレイ）に、青地に白い「T」マークのアイコンが表示されていること。
   - ※トレイの「^」（隠れているインジケーター）の中に格納されている場合はドラッグしてタスクバー上に表示させる。
2. **ツールチップ表示**:
   - アイコンにマウスカーソルを合わせた際、「tray-translate」というツールチップが表示されること。

### 4.2 トレイ格納（最小化・非表示）

1. **閉じるボタン（×）での格納**:
   - ウィンドウ右上の「×」ボタンをクリックする。
   - アプリケーションは終了せず、タスクバーの一覧からウィンドウが消え、タスクトレイにのみ常駐すること。
2. **「トレイに隠す」ボタンでの格納**:
   - ウィンドウ右上の「トレイに隠す」ボタンをクリックした場合も同様に、タスクバーから消えてトレイに隠れること。

### 4.3 トレイからの復帰・再表示

1. **アイコンクリックでの復帰**:
   - トレイアイコンを左クリック（またはダブルクリック）する。
   - 格納されていたウィンドウが画面上に再表示され、フォーカスが当たること。
2. **コンテキストメニューからの復帰**:
   - 再度ウィンドウを隠した状態で、トレイアイコンを右クリックする。
   - メニュー（「翻訳ウィンドウを表示」「終了」）が表示されること。
   - 「翻訳ウィンドウを表示」をクリックすると、ウィンドウが再表示されること。

### 4.4 アプリケーションの終了

1. **トレイメニューからの終了**:
   - トレイアイコンを右クリックし、「終了」をクリックする。
2. **ウィンドウヘッダーからの終了**:
   - ウィンドウ右上の「終了」ボタンをクリックする。
3. **完全終了の確認**:
   - ウィンドウおよびトレイアイコンが消失すること。
   - PowerShell またはタスクマネージャー等でプロセス（`tt-gui.exe`）が残存せず、完全に終了したことを確認する。

## 5. アイドル時モデル自動解放の確認手順 (Idle Memory Unload)

### 5.1 概要とテスト用設定

tray-translate は、翻訳完了後に未操作のまま一定時間（既定: 300 秒 = 5 分）経過すると、常駐メモリを削減するために自動でモデルインスタンスを解放する（PR #41 / Issue #29）。

手動テストを短時間で行うため、設定ファイルを編集して解放時間を 10 秒に短縮して検証する。

1. **設定ファイルの短縮変更**:
   - `%APPDATA%\tray-translate\settings.json` をエディタで開き、`"idle_unload_secs"` を `10` に書き換えて保存する（ファイルが存在しない場合は起動後に一度終了して生成するか、手動作成する）。
     ```json
     {
       "idle_unload_secs": 10
     }
     ```
2. **アプリ起動と翻訳実行**:
   - `cargo run -p tray-translate-gui` で起動する。
   - 手動でテキスト翻訳を 1 回実行する（モデルがメモリ上にロードされる）。
   - タスクマネージャーで `tray-translate-gui` のメモリ使用量（数十MB〜数百MB程度）を確認する。
3. **アイドル解放の確認**:
   - マウスやキーボードの入力を行わずに約 10 秒間放置する。
   - ステータスバーに「**しばらく使われなかったため、モデルを解放しました**」と表示されること。
   - タスクマネージャーでメモリ使用量が減少（解放）することを確認する。
4. **再翻訳時の自動再ロード確認**:
   - 解放状態のまま、再度「翻訳」ボタンをクリックする。
   - モデルが自動的に再読み込みされ、正常に翻訳結果が出力されること。

## 6. モデル管理とバックグラウンドダウンロードの確認手順 (Model Management)

### 6.1 完全オフライン方針と公式モデル一覧の取得

2. **一覧取得の実行**:

### 6.2 検索フィルターとバックグラウンドダウンロード
1. **モデル検索の絞り込み**:
   - 「モデル検索:」欄に `ja` または `Japanese` と入力し、該当する言語ペア（`en_ja`, `ja_en` 等）のみに絞り込まれることを確認する。
2. **ワンクリックダウンロードと進捗バー**:
   - 未導入のモデル（例: `ja` → `en`）の「取得」ボタンをクリックする。

   - 上部に「ダウンロード中: ja_en」および進行状況を示すプログレスバー（受信 MB / 総 MB、パーセント表記）が表示されること。
3. **完了と自動リフレッシュ**:

   - 「翻訳」タブに戻り、最下行の「導入済みのモデル:」にダウンロードしたモデルが追加され、即座に翻訳に使えることを確認する。

## 8. 不具合発生時のトラブルシューティング (Troubleshooting)

### Q1. 日本語が四角（豆腐: □）で表示される

- **原因**: Windows システムフォントの探索に失敗している。
- **確認手順**:
  - 起動直後のステータスバーに「日本語フォントが見つかりません（日本語が四角で表示される場合があります）」と表示されているか確認する。
  - Windows 標準のフォントディレクトリ（`C:\Windows\Fonts\`）に以下のいずれかのフォントファイルが存在するか確認する。
    - `YuGothM.ttc`（游ゴシック Medium）
    - `meiryo.ttc`（メイリオ）
    - `msgothic.ttc`（MS ゴシック）
- **対処**:
  - 特殊な Windows 環境や Server エディションでフォントが不足している場合は、Windows の「設定 > アプリ > オプション機能」から「日本語補助フォント」を追加インストールする。

### Q2. タスクトレイにアイコンが表示されない

- **原因 1**: Windows のタスクバー通知領域のオーバーフロー領域（「^」マークの中）に隠れている。
  - **対処**: タスクバー右下の「^」をクリックし、青い「T」アイコンを探してタスクバー上へドラッグ＆ドロップする。
- **原因 2**: トレイアイコンの初期化エラー。
  - **確認手順**: 起動時のコンソール出力（標準エラー出力）に `トレイアイコンの初期化をスキップしました: ...` というログが出力されていないか確認する。

### Q3. 「未導入のモデル」と表示されて翻訳できない

- **原因**: 指定した言語ペアのモデルパッケージがダウンロードされていないか、保存先パスが一致していない。
- **確認手順**:
  - 最下行の「導入済みのモデル:」に対象ペア（例: `en_ja`）が含まれているか確認する。
  - `%APPDATA%\tray-translate\packages` 配下にモデルディレクトリが存在するか確認する。
- **対処**:
  - `cargo run --release --bin tt -- download <from> <to>` を再実行する。
  - 環境変数 `TT_MODEL_DIR` をカスタム設定している場合は、GUI 実行環境でも同一の環境変数が設定されているか確認する。

### Q4. クリップボード監視を ON にしても自動翻訳されない

- **原因 1**: コピーしたテキストの文字数が範囲外（1 文字未満、または 5,000 文字超）。
  - **対処**: ステータスバーに「文字数が範囲外のため翻訳しませんでした」と表示されていないか確認し、適度な長さの英文をコピーする。
- **原因 2**: 前回と同じ文字列を連続してコピーしている。
  - **対処**: 異なる英文をコピーするか、一度別の文字列をコピーしてから再試行する。
