## 5. 記録上の注意

- [ ] Issue URLと取得日時を記録した。
- [ ] Issueの写しと現在の正本文書を混同していない。
- [ ] 決定事項がある場合は、関連する正本文書またはADRへのリンクを設定した。
- [ ] 機密情報、認証情報、利用者固有の情報を転記していない。
