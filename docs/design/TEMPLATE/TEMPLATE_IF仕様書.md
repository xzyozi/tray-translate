- **対象外**: [本書で扱わない連携]

### 1.2 単一責任範囲 (SSOT) と文書境界

- **本書の正本範囲**: `external_interface`。システム境界を越えて受け渡すAPI、メッセージ、認証、互換性の正本とする。
- **DDとの関係**: 内部のモジュール間DTO、制御フロー、状態遷移は詳細設計書 (DD)を正本とする。本書はDDの機能のうち、公開範囲が「外部公開」のものだけを対象とし、DDとは機能IDで対応付ける。
- **DSとの関係**: 保存後の形式は データ構造仕様書 (DS)を正本とする。外部から受け取った値を保存する場合は、受信形式（本書）と保存形式（DS）を別々に定義する。
- **BDとの関係**: 外部アクターと信頼境界の方針は基本設計書 (BD)を正本とし、本書はそれを接続契約へ具体化する。
- **他文書との関係**: 要求、環境、運用、テスト、ADR、レビュー文書はそれぞれの`ssot_scope`を正本とし、本書の契約を上書きしない。
- **責務の対象外**: [本書で定義せず、他の正本へ委譲する内容]
- **矛盾時の扱い**: 文書の更新日ではなく、該当する`ssot_scope`の正本を更新し、関連文書を追従させる。
